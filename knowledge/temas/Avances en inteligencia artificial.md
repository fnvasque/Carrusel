# Avances en inteligencia artificial

> Los avances en inteligencia artificial se centran en el desarrollo de modelos y herramientas que optimizan tareas específicas y mejoran la automatización.

## Lo esencial

- Claude Opus 5.5 es un modelo avanzado de IA que permite crear juegos y escenas 3D rápidamente.
- GPT-6 Sol y Luna son modelos de OpenAI con mejoras significativas, accesibles para más usuarios.
- Jev es una herramienta que optimiza decisiones específicas, complementando a los LLM generales y actuando como capa de verificación en sistemas RAG para evitar errores comunes.
- Jarvis OS 2.0 es un sistema automatizado que gestiona tareas diarias utilizando varias herramientas de IA.
- MiniMax es una herramienta para crear estilos de motion design en la plataforma OpenArt.

## Herramientas mencionadas

- **Claude Code + Codex** — Motor principal del sistema Jarvis OS 2.0 para gestionar tareas diarias.
- **Obsidian** — Almacenar y gestionar la memoria del sistema Jarvis OS 2.0.
- **Local Voice** — Entrada y salida de audio en el sistema Jarvis OS 2.0.
- **JEV** — Clasificar tareas, gestionar el flujo de trabajo y optimizar decisiones específicas.
- **Claude Opus 5.5** — Modelo de IA avanzado para crear juegos y escenas 3D.
- **GPT-6 Sol y Luna** — Modelos de IA de OpenAI con mejoras de Astra.
- **MiMo-V2.6** — Modelo de IA de Xiaomi con un billón de parámetros.
- **Muse Charm** — Tecnología de Meta para videollamadas de cuerpo completo.
- **MiniMax** — Crear estilos de motion design.
- **OpenArt** — Plataforma para crear diseños de movimiento.

## Técnicas

- Integrar Jev en sistemas RAG para evitar alucinaciones y contaminación del prompt.
- Usar Jev para filtrar contenido irrelevante en plataformas como X.
- Configurar filtros con Claude para decidir si un post es relleno.
