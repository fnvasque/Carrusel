# Automatización con IA

> Automatización de tareas mediante el uso de herramientas de inteligencia artificial.

## Lo esencial

- La automatización con IA permite optimizar y agilizar tareas diarias mediante sistemas operativos personalizados como Jarvis 2.0.
- Herramientas como Claude Code, Codex, y Obsidian son esenciales para construir sistemas que integran memoria, procesamiento de audio y interfaces de usuario.
- Empresas como Fastlane utilizan la IA para mejorar la interacción con clientes y aumentar los ingresos, integrando herramientas como Calendly y Notion para gestionar llamadas y evaluaciones de satisfacción.
- La creación de contenido automatizado, como sitios web animados, se facilita con herramientas de IA que permiten diseñar y ejecutar proyectos en minutos.

## Herramientas mencionadas

- **Claude Code** — Realizar el trabajo real del sistema operativo Jarvis 2.0 y crear dashboards de inteligencia interna.
- **Codex** — Realizar el trabajo real del sistema operativo Jarvis 2.0.
- **Obsidian** — Almacenar la memoria del sistema operativo Jarvis 2.0.
- **Whisper** — Procesar el audio localmente en el sistema operativo Jarvis 2.0.
- **Kokoro** — Responder en voz alta en el sistema operativo Jarvis 2.0.
- **Jev** — Clasificar y enrutar solicitudes en el sistema operativo Jarvis 2.0.
- **Cockpit** — Proveer la interfaz del sistema operativo Jarvis 2.0.
- **HUD** — Proveer la interfaz del sistema operativo Jarvis 2.0.
- **Fastlane** — Crear contenido corto con IA para solopreneurs.
- **Calendly** — Agendar llamadas con clientes.
- **Notion** — Almacenar notas de las llamadas.
- **Opus 5.5** — Crear sitios web animados en 5 minutos.
- **Prompts Library** — Proveer prompts para el diseño del sitio web.

## Técnicas

- Conectar el cerebro del sistema operativo con herramientas como Claude Code o Codex.
- Construir la memoria del sistema con Obsidian.
- Añadir capacidades de voz con Whisper y Kokoro.
- Instalar interfaces de usuario con Cockpit y HUD.
- Utilizar dashboards internos para evaluar la satisfacción del cliente.
- Crear secciones de héroe animadas en sitios web en minutos usando prompts y herramientas de diseño.
