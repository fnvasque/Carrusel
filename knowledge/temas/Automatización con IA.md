# Automatización con IA

> La automatizaci3n con IA se refiere al uso de herramientas y sistemas de inteligencia artificial para realizar tareas de manera autom1tica y eficiente.

## Lo esencial

- La automatización con IA permite configurar sistemas que realizan tareas diarias de manera automática, como el sistema operativo Jarvis 2.0.
- Herramientas de IA como Claude, Codex y Obsidian se utilizan para realizar tareas específicas dentro de un sistema automatizado.
- La automatización puede aplicarse en diversos campos, como la creación de contenido, la simulación de entrevistas de trabajo y la gestión de interacciones con clientes.
- El uso de IA en la automatización permite optimizar procesos, mejorar la eficiencia y personalizar experiencias, como se ve en el caso de Fastlane y su éxito en la monetización.
- La creación de sitios web animados y otras aplicaciones visuales también puede ser automatizada utilizando herramientas de IA.

## Herramientas mencionadas

- **Claude Code** — Realizar el trabajo real del sistema operativo automatizado.
- **Codex** — Realizar el trabajo real del sistema operativo automatizado.
- **Obsidian** — Almacenar la memoria del sistema automatizado.
- **Whisper** — Procesar el audio localmente en sistemas automatizados.
- **Kokoro** — Responder en voz alta en sistemas automatizados.
- **Jev** — Clasificar y enrutar solicitudes en sistemas automatizados.
- **Cockpit** — Proveer la interfaz del sistema automatizado.
- **HUD** — Proveer la interfaz del sistema automatizado.
- **Fastlane** — Herramienta de contenido corto con IA para solopreneurs.
- **Calendly** — Agendar llamadas con clientes.
- **Notion** — Almacenar notas de las llamadas.
- **Opus 5.5** — Crear sitios web animados en 5 minutos.
- **Prompts Library** — Proveer prompts para el diseño del sitio web.

## Técnicas

- Conectar el cerebro del sistema usando herramientas como Claude Code o Codex.
- Construir la memoria del sistema con Obsidian.
- Añadir capacidades de voz con Whisper y Kokoro.
- Instalar interfaces de usuario con Cockpit y HUD.
- Simular entrevistas de trabajo con Claude para mejorar habilidades de respuesta.
- Utilizar un dashboard interno para evaluar la satisfacción del cliente con herramientas como Claude.
- Crear secciones de héroe animadas en sitios web en 5 minutos usando Opus 5.5 y prompts específicos.
