# Producción de contenido automatizado

> La produccin de contenido automatizado implica el uso de herramientas de inteligencia artificial para crear diversos tipos de contenido de manera rpida y eficiente.

## Lo esencial

- La produccin de contenido automatizado utiliza herramientas de IA para crear videos, sitios web, anuncios y ms sin necesidad de intervencin humana directa.
- Seedance 2.5 permite crear videos UGC en 5 minutos, automatizando todo el proceso desde la idea hasta la publicacin.
- Herramientas como Claude y Opus 5.5 facilitan la creacin rpida de sitios web y otros contenidos visuales.
- Magnifique se utiliza para transformar fotos en anuncios animados, mientras que Minimax H3 Max mejora la calidad de los videos generados.
- El uso de IA en la produccin de contenido permite personalizar y optimizar el contenido para diferentes plataformas y audiencias.

## Herramientas mencionadas

- **Seedance 2.5** — Generar videos UGC automatizados con IA.
- **WhatsApp Agent Kit** — Automatizar la atencin al cliente en WhatsApp.
- **Claude WebKit** — Crear pginas web profesionales en minutos.
- **Claude Banana** — Generar instrucciones para crear imgenes con IA.
- **Proyecto Maya** — Realizar anlisis de mercado automatizados.
- **Editor ProMax** — Automatizar la edicin de videos.
- **ChatGPT** — Mejorar fotos de comida con aspecto gourmet.
- **Magnifique** — Generar video animado del men.
- **Minimax H3 Max** — Modelo para generar videos animados en Magnifique.
- **Claude Code** — Realizar el trabajo real del sistema.
- **Codex** — Realizar el trabajo real del sistema.
- **Obsidian** — Almacenar la memoria del sistema.

- **Kokoro** — Responder en voz alta.
- **Jev** — Clasificar y enrutar solicitudes.
- **Cockpit** — Proveer la interfaz del sistema.
- **HUD** — Proveer la interfaz del sistema.
- **Opus 5.5** — Crear sitios web animados en 5 minutos.
- **Prompts Library** — Proveer prompts para el diseo del sitio web.

## Técnicas

- Usar Seedance 2.5 para crear videos UGC en 5 minutos.
- Transformar fotos de comida en anuncios animados con ChatGPT y Magnifique.
- Crear sitios web animados en 5 minutos usando Opus 5.5 y Claude.
- Automatizar la edicin de videos con Editor ProMax.
