# Preparación de entrevistas con Claude

> Tema: [[Automatización con IA]]

## Qué es

El post describe cómo usar Claude para simular entrevistas de trabajo.

## Ideas clave

- Usar Claude para simular entrevistas de trabajo.
- Claude actúa como el gerente de contratación.
- Recibir calificaciones y retroalimentación para mejorar respuestas.
- Realizar la simulación durante 30-45 minutos.
- Mejorar respuestas débiles y fortalecer las fuertes.

## Herramientas

- **Claude** — Simular entrevistas de trabajo y proporcionar retroalimentación.

## Pasos

1. Pedir a Claude que actúe como gerente de contratación.
2. Responder preguntas una a una.
3. Recibir calificación y retroalimentación después de cada respuesta.
4. Repetir el proceso durante 30-45 minutos.
