## Qué es

El post describe un proceso donde un agente de IA puede escribir sus propias herramientas en Python cuando no tiene una disponible para una tarea específica.

## Ideas clave

- El agente de IA puede escribir una función en Python si no tiene una herramienta disponible.
- Un guardián revisa el código fuente y puede rechazarlo con una razón.
- El código se prueba en una sandbox con entradas nuevas antes de ser aceptado.
- Una vez aceptado, el código se añade a la lista de herramientas del agente.
- El proceso completo puede reducir significativamente el uso de tokens en tareas repetitivas.
