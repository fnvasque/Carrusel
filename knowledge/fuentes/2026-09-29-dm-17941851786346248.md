## Qué es

El post presenta una configuración automatizada llamada Jarvis OS 2.0 que integra varias herramientas para gestionar tareas diarias.

## Ideas clave

- Jarvis OS 2.0 es una configuración automatizada para gestionar tareas diarias.
- Utiliza Claude Code + Codex como motor principal.
- Obsidian se emplea para la memoria del sistema.
- La voz local actúa como entrada y salida de audio.
- JEV clasifica las tareas y gestiona el flujo de trabajo.
- Incluye dos paneles de control para la interfaz visual.

## Herramientas

- **Claude Code + Codex** — Funciona como el motor principal del sistema.
- **Obsidian** — Se utiliza para almacenar y gestionar la memoria del sistema.
- **Local Voice** — Actúa como entrada y salida de audio.
- **JEV** — Clasifica las tareas y gestiona el flujo de trabajo.
- **Two Dashboards** — Proporciona la interfaz visual del sistema.
