## Qué es

El post presenta cinco proyectos basados en Claude para ofrecer servicios automatizados y generar ingresos, incluso sin experiencia previa.

## Ideas clave

- WhatsApp Agent Kit automatiza la atención al cliente.
- Claude Web Kit permite crear páginas web rápidamente.
- Claude Banana genera instrucciones para imágenes AI.
- Proyecto Maya realiza análisis de mercado automatizado.
- Editor Pro Max automatiza la edición de video.

## Herramientas

- **WhatsApp Agent Kit** — Automatizar la atención al cliente en WhatsApp.
- **Claude Web Kit** — Crear páginas web profesionales rápidamente.
- **Claude Banana** — Generar instrucciones para crear imágenes con AI.
- **Proyecto Maya** — Realizar análisis de mercado automatizado.
- **Editor Pro Max** — Automatizar la edición de video.
