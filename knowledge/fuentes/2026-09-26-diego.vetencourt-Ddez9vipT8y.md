## Qué es

El post describe cinco proyectos usando Claude para ofrecer servicios que generan ingresos sin tener cliente previo.

## Ideas clave

- WhatsApp Agent Kit automatiza la atención al cliente en WhatsApp.
- Cloud WebKit permite crear páginas web profesionales rápidamente.
- Cloud Banana genera descripciones de imágenes IA para mejorar productos.
- Proyecto Maya facilita el análisis de oportunidades de mercado.
- Editor Pro Max edita videos de manera automatizada.

## Herramientas

- **Claude** — Implementar los diversos proyectos propuestos.
- **WhatsApp Agent Kit** — Crear agentes automatizados para atención en WhatsApp.
- **Cloud WebKit** — Desarrollar páginas web profesionales en minutos.
- **Cloud Banana** — Generar descripciones detalladas para imágenes de IA.
- **Proyecto Maya** — Realizar análisis de oportunidades de mercado con IA.
- **Editor Pro Max** — Automatizar la edición de videos.
