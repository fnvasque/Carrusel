# Crear anuncios de menú con IA

## Qué es

El post muestra cómo transformar fotos de comida en anuncios animados usando IA.

## Ideas clave

- Usar ChatGPT para mejorar fotos de comida.
- Crear un menú estructurado con precios usando IA.
- Generar un video animado del menú con Magnifique.
- Seleccionar el modelo Minimax H3 Max para mejor resultado.
- El proceso no requiere diseñador gráfico.

## Herramientas

- **ChatGPT** — Mejorar fotos de comida con aspecto gourmet. ([link](https://chatgpt.com))
- **Magnifique** — Generar video animado del menú. ([link](https://magnifique.com))
- **Minimax H3 Max** — Modelo para generar videos animados en Magnifique.

## Pasos

1. Subir fotos de comida a ChatGPT y pedir mejoras.
2. Crear un menú con precios usando las fotos mejoradas.
3. Usar Magnifique para crear un video animado del menú.
4. Seleccionar el modelo Minimax H3 Max en Magnifique.
5. Configurar el video con animaciones 3D de los platos.

## De los comentarios

- Magnifique no es gratis y puede ser costoso.
- Consulta sobre herramientas gratuitas para hacer videos.
