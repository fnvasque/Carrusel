# Creación de sitios web animados en 5 minutos

## Qué es

El post muestra cómo crear una sección de héroe animada en un sitio web en solo 5 minutos usando herramientas de IA.

## Ideas clave

- El video de héroe no tiene bucles, se detiene en el último fotograma.
- El nombre en el fondo se mezcla para que el pájaro siempre esté al frente.
- Se utiliza una animación de un martín pescador para la sección de héroe.
- El proyecto completo incluye el prompt de video, el prompt del sitio web y el HTML.
- El diseño se realiza con Opus 5.5 en combinación con otras herramientas.

## Herramientas

- **Opus 5.5** — Crear sitios web animados en 5 minutos.
- **Claude** — Procesar y ejecutar el prompt del sitio web.
- **Prompts Library** — Proveer prompts para el diseño del sitio web.
