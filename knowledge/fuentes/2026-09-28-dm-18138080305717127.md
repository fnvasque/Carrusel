## Qué es

El post describe cinco habilidades de diseño para instalar en Claude Code, mejorando la creación de proyectos interactivos y visualmente atractivos.

## Ideas clave

- Claude Code puede instalar habilidades para mejorar proyectos.
- Las habilidades incluyen Three.js, GSAP, Design DNA, Motion Design y Genjutsu.
- Three.js permite crear escenas 3D interactivas.
- GSAP ofrece animaciones fluidas y control de desplazamiento.
- Design DNA extrae y aplica el diseño de sitios web existentes.
- Motion Design facilita animaciones Lottie y SVG.
- Genjutsu aporta dirección creativa y pulido final.

## Herramientas

- **Three.js** — Crear escenas 3D interactivas.
- **GSAP** — Animaciones fluidas y control de desplazamiento.
- **Design DNA** — Extraer y aplicar diseño de sitios web.
- **Motion Design** — Facilitar animaciones Lottie y SVG.
- **Genjutsu** — Aportar dirección creativa y pulido final.
