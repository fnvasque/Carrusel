## Qué es

El post describe cómo configurar un sistema operativo Jarvis 2.0 utilizando diversas herramientas de IA para automatizar tareas diarias.

## Ideas clave

- Jarvis OS 2.0 se instala con un solo prompt y automatiza el día completo.
- Jev es un clasificador que optimiza el enrutamiento de solicitudes en menos de un segundo.
- El sistema se compone de cinco partes: Claude Code/Codex, Obsidian, Whisper/Kokoro, Jev y Cockpit/HUD.
- Cada parte del sistema tiene una función específica, desde la memoria hasta la interfaz de usuario.
- El proceso incluye conectar el cerebro, construir la memoria, añadir la voz e instalar la interfaz.

## Herramientas

- **Claude Code** — Realizar el trabajo real del sistema.
- **Codex** — Realizar el trabajo real del sistema.
- **Obsidian** — Almacenar la memoria del sistema.
- **Whisper** — Procesar el audio localmente.
- **Kokoro** — Responder en voz alta.
- **Jev** — Clasificar y enrutar solicitudes.
- **Cockpit** — Proveer la interfaz del sistema.
- **HUD** — Proveer la interfaz del sistema.

## Pasos

1. Conectar el cerebro usando Claude Code o Codex.
2. Construir la memoria con Obsidian.
3. Añadir la voz con Whisper y Kokoro.
4. Instalar la interfaz con Cockpit y HUD.
